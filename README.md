# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe Game** built using **HTML, CSS, and JavaScript**.

## 📌 About the Project

This project is a browser-based Tic Tac Toe game where the player can choose **X or O** and play against the computer.

The computer automatically makes a random move after the player's turn.

## ✨ Features

* 🎮 Player vs Computer
* ❌ Choose X or O
* 🤖 Computer makes random moves
* 🏆 Winner detection
* 🤝 Draw detection
* 🔄 Restart game option
* 🎨 Highlight winning cells
* 💻 Responsive and simple interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* Vercel for deployment

## 🎯 How to Play

1. Choose **X** or **O**.
2. Click on an empty cell.
3. The computer will automatically make its move.
4. Get three matching symbols in a row, column, or diagonal to win.
5. If all cells are filled without a winner, the game ends in a draw.
6. Click **Restart** to play again.
